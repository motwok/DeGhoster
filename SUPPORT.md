# Getting help

Need help with DeGhoster? Here's where to look, in order:

1. **Read the docs**
   - [User Manual](docs/UserManual.md) — how to use it, plus a Troubleshooting section.
   - [Install guide](docs/Install.md) — installation, language selection, uninstall.
   - [README](README.md) — overview and links to everything else.

2. **Search existing issues** — your question may already be answered:
   <https://github.com/motwok/DeGhoster/issues?q=is%3Aissue>

3. **Open an issue** if you don't find an answer:
   - 🐞 [Bug report](https://github.com/motwok/DeGhoster/issues/new?template=bug_report.yml)
   - 💡 [Feature request](https://github.com/motwok/DeGhoster/issues/new?template=feature_request.yml)

## Please note

- 🔒 **Security problems** are **not** reported as public issues — see
  [SECURITY.md](SECURITY.md) for private reporting.
- 🙅 **Pull requests are not accepted** — see [CONTRIBUTING.md](CONTRIBUTING.md).
- ⏱️ This is a single-maintainer project, so help is best-effort — thanks for your
  patience.
